Same effect with shipping.name or shipping.address that are not text, for example {"name":5,"address":5} (TypeError: shipping.name.trim is not a function).
Root cause: Express 4 does not catch errors thrown inside an async route handler, so the unhandled rejection terminates the Node process. api.ts reads item.productId / shipping.name.trim() without validating the types.
